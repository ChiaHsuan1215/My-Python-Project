# Python Interactive Guessing Game 🎮

## Overview
This project is a simple text-based interactive game built with Python.  
Players make choices that lead to different outcomes, allowing them to experience multiple story paths.

The project demonstrates my ability to design basic program flow, handle user input, and structure a small but complete software project.

---

## Motivation
I created this project as a portfolio piece for interviews.  
The goal was to practice Python programming fundamentals while simulating how to design a user-facing interactive application.

---

## Features
- Text-based user interaction through the command line
- Multiple choices that lead to different endings
- Clear and readable program structure
- Easy to extend with additional story branches

---

## How to Run the Game
1. Make sure Python is installed on your system  
2. Clone this repository
3. Run the following command in the project directory:

```bash
python main.py
